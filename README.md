## What Is MIRU?

MIRU isn't another generic anime list app. It’s an architectural telemetry dashboard designed for high-density anime data analysis.

It replaces standard page-hopping CRUD flows with an editorial command-center experience:

- **Quick Telemetry Drawer:** Slide-out drawer system triggering instantaneous anime data previews across any view without breaking scroll state or forcing full-page reloads.
- **Categorical Vault Manager:** Multi-status watchlist management (*Plan to Watch*, *Watching*, *Completed*, *Favorites*) persisted in high-speed local storage with cross-component event reactivity.
- **Versus Comparison Matrix:** Side-by-side head-to-head metric battle arena comparing score distribution, broadcast length, and popularity ranks between combatants.
- **Cybernetic Command Telemetry:** Dual-tab analytics suite parsing global industry trends alongside personalized vault statistics via custom gradient Recharts visualizers.
- **Command Palette & Keyboard First:** Global keybindings (`/` search trigger, quick dossier toggles) engineered for zero-latency keyboard navigation.

## Design Philosophy

- **Kurogane Editorial Aesthetic:** Deep jet-black tones (`#09090b`), high-contrast crimson accents (`#ff2e4d`), tech-grid backgrounds, and manga halftone speedline overlays.
- **Zero-Drop Interactions:** Every component transition uses hardware-accelerated spring physics and staggered entry sequences.
- **Typography with Intent:** JetBrains Mono for telemetry metrics, Noto Sans JP for editorial subheads, and Outfit for high-impact display titles.
- **1-Thumb Touch Architecture:** Native app-like mobile experience complete with persistent bottom navigation and mobile-optimized slide sheets.

## Running Locally

Clone the repository, install dependencies, and launch the dev server:

```bash
# 1. Clone the repository
git clone https://github.com/GhananilShirpurkar/Miru.git

# 2. Navigate to directory
cd MIRU

# 3. Install dependencies
npm install

# 4. Start local dev server
npm run dev
```

Build for production:

```bash
npm run build
```
